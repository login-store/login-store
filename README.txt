Login Store - متجر إكسسوارات الهاتف
===================================

هيكل المشروع
------------
login-store/
  index.html          الصفحة الرئيسية
  shop.html           صفحة المنتجات
  why.html            صفحة لماذا نحن
  faq.html            صفحة الأسئلة الشائعة
  contact.html        صفحة تواصل معنا
  robots.txt
  assets/
    css/style.css     التنسيق والألوان (الألوان في أعلى الملف)
    js/app.js         منطق الموقع: عرض المنتجات، السلة، وضع التعديل
    js/data.js        بيانات المتجر: المنتجات، التصنيفات، الإعدادات، الأسئلة
    img/logo.webp     الشعار الكامل
    img/logo-icon.webp  أيقونة الشعار (للقائمة والتبويب)

النشر
-----
ارفع المجلد كاملًا بنفس الهيكل:
1) Netlify: افتح app.netlify.com/drop واسحب المجلد login-store.
2) GitHub Pages: ارفع الملفات في مستودع ثم فعّل Pages من Settings.
3) cPanel: ارفع الملفات داخل public_html.
لربط دومين خاص اتبع إعدادات الدومين عند مزوّد الاستضافة.

لا يحتاج الموقع إلى خادم أو قاعدة بيانات. كل شيء ملفات ثابتة.

النشر التلقائي للتعديلات (موصى به)
---------------------------------
بدل رفع data.js يدويًا، ترفعه لوحة التحكم تلقائيًا إلى GitHub، وتنشره الاستضافة وحدها.
إعداد مرة واحدة:
1) أنشئ حسابًا على github.com ثم مستودعًا جديدًا (مثل login-store)، وارفع إليه كل ملفات هذا المجلد.
2) اربط المستودع باستضافة تنشر عند كل تحديث:
   - Netlify: Add new site > Import an existing project > اختر المستودع.
   - أو GitHub Pages: Settings > Pages > اختر الفرع main.
3) أنشئ رمز وصول: GitHub > Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
   - Repository access: Only select repositories > اختر مستودع المتجر.
   - Permissions > Repository permissions > Contents: Read and write.
4) افتح index.html?admin > تعديل الموقع > إعدادات الموقع > تبويب «النشر التلقائي».
   أدخل اسم المستخدم واسم المستودع والفرع (main) والمسار (assets/js/data.js) والرمز، ثم «اختبار الاتصال».
5) بعد ذلك عدّل ما تريد واضغط «حفظ ونشر». يظهر التحديث للزوار خلال دقائق.
مهم: الرمز يُحفظ في متصفحك فقط، فلا تستخدمه على جهاز مشترك. ومن لا يملك الرمز لا يستطيع النشر حتى لو فتح ?admin.

تعديل المتجر (الطريقة اليدوية بدون GitHub)
-----------------------------
1) افتح أي صفحة بإضافة ?admin للرابط، مثل: loginstore.com/index.html?admin
2) اضغط «تعديل الموقع»، ثم عدّل المنتجات والتصنيفات والإعدادات وارفع صور المنتجات.
3) اضغط «تنزيل data.js» من الشريط السفلي.
4) ارفع data.js الجديد إلى المجلد assets/js بدل القديم.
التعديلات لا تظهر للزبائن قبل رفع data.js. ومن يفتح ?admin لا يغيّر شيئًا إلا في متصفحه.

تعديل المتجر (يدويًا)
---------------------
افتح assets/js/data.js بأي محرر نصوص وعدّل القيم مباشرة، ثم احفظ وارفع الملف.

تنبيهات
-------
- أدخل رقم واتساب المتجر في settings.whatsapp (بالصيغة الدولية بدون +، مثل 201001234567) وإلا لن تعمل السلة.
- المنتجات والأسعار الموجودة أمثلة، عدّلها.
- عنوان ووصف كل صفحة في ملف HTML الخاص بها (وسوم title و meta) للتحسين في محركات البحث.
- الدفع الإلكتروني غير مضمّن. الطلبات تصل عبر واتساب والدفع عند الاستلام.
