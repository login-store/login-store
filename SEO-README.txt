تحسين ظهور المتجر في جوجل - طريقة التحديث
==========================================

ما الجديد؟
- كل صفحة صار لها عنوان ووصف خاصان، ورابط أصلي (canonical)، وصورة مشاركة، وبيانات منظّمة (Store وProduct وFAQ).
- محتوى المنتجات والأسئلة صار موجودًا داخل ملف HTML نفسه، فيقرؤه جوجل مباشرة بدون انتظار تشغيل الجافاسكربت.
- ملف build.js يولّد هذه الصفحات من assets/js/data.js، وملف .github/workflows/build.yml يشغّله تلقائيًا
  كلما نشرت تعديلًا من لوحة التحكم (حفظ ونشر)، فتبقى الصفحات مطابقة لمنتجاتك دائمًا.

التركيب (مرة واحدة)
1) فك ضغط الملف.
2) في GitHub: Add file > Upload files، ثم اسحب كل محتويات المجلد بما فيها المجلدان assets و .github
   (في ماك: اضغط Cmd+Shift+. لإظهار المجلدات المخفية. أو أنشئ الملف يدويًا: Add file > Create new file واكتب الاسم
   .github/workflows/build.yml والصق محتواه).
3) اضغط Commit changes.
4) افتح تبويب Actions في المستودع. إن ظهرت رسالة تطلب تفعيل الـ workflows اضغط الزر الأخضر لتفعيلها.
5) اختر Build SEO pages من القائمة اليسرى ثم Run workflow ثم Run workflow.
   هذه الخطوة تبني الصفحات من بياناتك الحقيقية (لا من الأمثلة). وبعدها تعمل تلقائيًا مع كل نشر.

ربط دومين خاص لاحقًا
غيّر الرابط في أول ملف build.js (السطر الذي فيه SITE) إلى دومينك، ثم شغّل Run workflow مرة أخرى.

داخل لوحة التحكم (إعدادات الموقع)
- أدخل حسابات فيسبوك وإنستغرام وتيك توك، لأنها تُضاف تلقائيًا لبيانات المتجر المنظّمة.
- أدخل رقم الواتساب والهاتف والعنوان ومواعيد العمل.
