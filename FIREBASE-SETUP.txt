تفعيل استقبال الطلبات في صفحة الأدمن (مجاني، بدون واتساب)
===========================================================

الفكرة: العميل يضغط "تأكيد الطلب" فيُحفظ الطلب في قاعدة بيانات Firebase (الخطة المجانية Spark)،
وتشوفه أنت في صفحة admin.html بعد تسجيل الدخول ببريدك وكلمة مرورك.

الخطوة 1: إنشاء المشروع
  1. ادخل https://console.firebase.google.com بحساب جوجل.
  2. Create a project / إنشاء مشروع. اكتب أي اسم (مثلًا login-store). عطّل Google Analytics. اضغط Create.

الخطوة 2: إنشاء قاعدة البيانات
  1. من القائمة: Build ثم Firestore Database ثم Create database.
  2. اختر Production mode ثم اختر موقعًا قريبًا (مثلًا eur3 أو europe-west). اضغط Enable.

الخطوة 3: القواعد (مهمة للأمان)
  1. داخل Firestore افتح تبويب Rules.
  2. امسح كل المحتوى والصق محتوى ملف firestore.rules.
  3. غيّر ADMIN_EMAIL@gmail.com إلى بريدك الذي ستدخل به الأدمن.
  4. اضغط Publish.

الخطوة 4: حساب المالك
  1. Build ثم Authentication ثم Get started.
  2. Sign-in method ثم فعّل Email/Password ثم Save.
  3. تبويب Users ثم Add user: اكتب نفس بريد الخطوة 3 وكلمة مرور قوية.
  (لا تعطِ كلمة المرور لأي أحد، ولا تكتبها في أي شات.)

الخطوة 5: بيانات الربط
  1. اضغط أيقونة الترس بجانب Project Overview ثم Project settings.
  2. في General: انسخ Project ID، وانسخ Web API Key.
     إن لم يظهر Web API Key: أضف تطبيق ويب (أيقونة </>) واكتب أي اسم، وستجده في apiKey.
  3. افتح متجرك بإضافة ?admin للرابط، ثم "إعدادات الموقع"، والصق القيمتين في آخر الصفحة
     (Project ID و Web API Key)، ثم "حفظ ونشر".
     هذه المفاتيح ليست أسرارًا، وحمايتك الحقيقية هي القواعد في الخطوة 3.

الخطوة 6: ارفع الملفات الجديدة إلى GitHub
  admin.html  /  assets/js/app.js  /  assets/js/orders.js  /  assets/css/admin.css  /  assets/css/style.css  /  build.js
  (حافظ على أسماء المجلدات. لا ترفع data.js من هذا الملف حتى لا تمسح منتجاتك.)

الاستخدام
  - افتح: https://login-store.github.io/login-store/admin.html (أو زر "الطلبات" في شريط وضع التعديل).
  - سجّل الدخول. الصفحة تتحدث كل 30 ثانية وتصدر صوتًا عند وصول طلب جديد وهي مفتوحة.
  - من كل طلب: غيّر الحالة، اتصل بالعميل، أو احذف الطلب.

ملاحظات صريحة
  - الإجمالي يُحسب في متصفح العميل، لذلك أكّد السعر مع العميل في مكالمة التأكيد.
  - الخطة المجانية تكفي متجرًا صغيرًا بسهولة (حدود يومية كبيرة للقراءة والكتابة).
  - الصفحة تنبّه فقط وهي مفتوحة. للتنبيه على الموبايل اترك الصفحة مفتوحة أو افتحها من وقت لآخر.
  - لو لم تُدخل بيانات Firebase، يعود الزر القديم (واتساب) تلقائيًا إن كان رقم واتساب مضبوطًا.


==========================================================
تحديث: صفحة لكل منتج + حسابات العملاء
==========================================================

1) حسابات العملاء (تسجيل دخول وإنشاء حساب)
   - تستخدم نفس مشروع Firebase ونفس Email/Password المفعّل من قبل. مفيش إعدادات جديدة في Authentication.
   - لازم تحدّث القواعد (مهم، وإلا الطلبات لن تُربط بالحساب وصفحة الحساب لن تعمل):
       Firestore Database ثم Rules، امسح القديم والصق محتوى ملف firestore.rules الجديد،
       غيّر ADMIN_EMAIL@gmail.com إلى بريدك (بحروف صغيرة)، واضغط Publish.
   - القواعد الجديدة:
       * الزائر يستطيع إرسال طلب (بدون حساب) كما كان.
       * العميل المسجّل يُحفظ طلبه باسم حسابه ويرى طلباته هو فقط.
       * أنت (بريد المالك) ترى وتعدّل كل الطلبات في admin.html كما كان.
       * بيانات كل عميل (الاسم والهاتف والعنوان) لا يصل إليها غيره.
   - رسالة استعادة كلمة المرور تُرسل من Firebase. لتعريبها: Authentication ثم Templates ثم Password reset.
   - الرسائل قد تصل في «غير المرغوب فيه» أول مرة.

2) صفحة مستقلة لكل منتج
   - كل منتج له صفحة (product.html?id=...) فيها معرض صور، سعر وخصم، كمية، وصف تفصيلي، مواصفات، ومنتجات مشابهة.
   - بالإضافة لصفحات ثابتة product-<رقم>.html يبنيها build.js تلقائيًا لمحركات البحث (تظهر في sitemap.xml).
   - من وضع التعديل (?admin) افتح «منتج جديد» أو عدّل منتجًا، وستجد:
       * الوصف التفصيلي (افصل الفقرات بسطر فارغ)
       * المواصفات (سطر لكل خاصية بالشكل: الخامة: سيليكون)
       * صور متعددة (حتى 8): أول صورة هي الرئيسية، ويمكنك تغيير الرئيسية أو حذف أي صورة.
   - الصور المرفوعة تتحول تلقائيًا إلى ملفات في assets/img/products ويُخفَّف ملف data.js بعد أول تشغيل للـ Action.

3) رفع التحديث إلى GitHub
   ارفع مع الحفاظ على المجلدات (لا ترفع data.js):
     account.html  product.html  build.js  firestore.rules
     assets/js/app.js  assets/js/account.js  assets/css/style.css
     .github/workflows/build.yml   (اختياري، يمنع تعارض النشر. المجلد مخفي على ماك، اضغط Cmd+Shift+. لإظهاره)
   بعد الرفع افتح تبويب Actions وانتظر علامة ✓ خضراء، فتُبنى صفحات المنتجات وتتحدّث باقي الصفحات.
